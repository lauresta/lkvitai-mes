# Вертикальные жалюзи «Трапеция»: расчёт и производственный документ

Дата: 2026-11-06. Статус: задания и проверяемый прототип, без изменения рабочего приложения.

Добавляем в **Gamyba → Documents → Production documents** пункт **Vertikalios · Trapecija**. Это форма уточнения размеров, расчёт ламелей и печатный документ с динамической схемой. Excel остаётся эталоном расчёта.

## Что открыть

- [Интерактивный прототип](preview.html): автоподстановка примеров A/B, редактирование размеров, 89/127 мм, выступ, зеркальный вид, выбор ламели на схеме и в таблице, печать.
- [Задание дизайнеру](designer-task.md): экран, ввод, схема, печатная форма, состояния и критерии приёмки.
- [Задание разработчику / Codex](implementation-task.md): интеграция с живыми заказами/GU, правила автозаполнения, сохранение уточнений, алгоритм и проверки.
- [Разбор Excel](excel-analysis.md): источники, VBA, формулы, таблицы, эталонные значения и особенности переноса.

## Решения из обсуждения

1. Gamyba **уже работает с настоящими данными**. Новый функционал встраивается в этот контур. Найденные в локальной ветке fixtures не описывают актуальное развёртывание целиком.
2. Рабочий сценарий Excel: выбрать заказ → изделие/лист A или B → уточнить ширину ламели, ширину изделия, две высоты и выступ → рассчитать → печатать. В web эти input-поля обязательны.
3. A/B пытаемся получить из управления изделия в заказе. 89/127 мм — из материала. Ширину и большую высоту — из заказа. Малую высоту и выступ также подставляем при наличии. Ручной ввод остаётся fallback и способом явного уточнения.
4. `+45 мм` на длину ламели и `+27 мм` на расход сохраняем. Пользователь подтвердил Excel как правильный эталон, хотя назначение добавок сейчас не помнит. Переосмыслять или удалять их не требуется.
5. Схема строится по рассчитанному массиву ламелей. Переключение A/B меняет технологический расчёт; зеркальность изображения является отдельным свойством.
6. Изменённые размеры сохраняются в расчёте/версии документа. Автоматическая запись этих уточнений обратно в Sales не входит в задачу.
