# Trikčių šalinimas

**Būsena:** veikia

## Kam skirta
Šiame skyriuje rasite dažniausiai pasitaikančių problemų, dirbant su sandėlio moduliu (Warehouse), sprendimus: prisijungimą, atsargų kiekius, spausdinimą, duomenų vėlavimą, rezervacijas, pirkimo dokumentų registravimą, siuntimą į Agnum ir mėnesio uždarymą.

## Greita pagalba
- Nepavyksta prisijungti: [Dažnos klaidos](daznos-klaidos.md#prisijungimas)
- Atsargų kiekiai nesutampa: [Dažnos klaidos](daznos-klaidos.md#atsargu-kiekiai)
- Spausdintuvas nereaguoja: [Dažnos klaidos](daznos-klaidos.md#spausdintuvas)
- Projekcijų vėlavimas (Lag): [Dažnos klaidos](daznos-klaidos.md#projekcijos)
- Rezervacijos negalima atšaukti: [Dažnos klaidos](daznos-klaidos.md#rezervacijos)
- Pirkimo dokumento neužregistruoja: [Dažnos klaidos](daznos-klaidos.md#pirkimo-dokumentas)
- Dokumentas nepatenka į Agnum: [Dažnos klaidos](daznos-klaidos.md#agnum-eile)
- Mėnesio negalima uždaryti: [Dažnos klaidos](daznos-klaidos.md#menesio-uzdarymas)

## Žurnalai
Sistemos audito žurnalas pasiekiamas per (UI: Admin > Audit Logs) ir skirtas administratoriui (WarehouseAdmin), žr. [P-31](../procesai/P-31-auditas-saugojimas-gdpr-kopijos.md). Agnum konfigūracijos pakeitimus rodo kortelė (UI: Change log) ekrane (UI: Finance > Agnum Accounting).

## Kontaktai
Dėl klaidų, kurių negalite išspręsti patys, kreipkitės į sistemos administratorių ar IT pagalbos tarnybą ir nurodykite `Trace ID`, jei jis rodomas. Kontaktinė informacija šiame puslapyje dar neįrašyta.
